# 식단·재고·체중 관리 웹앱 — 화면 목록 (1차 범위)

버전: v0.1 초안 (2026-11-03) / 근거: [`requirements-phase1.md`](requirements-phase1.md), [`erd.md`](erd.md), [`state-transitions.md`](state-transitions.md) / 전달 대상: Claude Code

세 루트 문서의 기능 요구(FR-01~09)·엔터티·상태 기계를 **화면 단위**로 재배열했다. 화면 ID·경로·탭 구성은 모두 **[제안]**이며 사용자 확정 사항이 아니다. 색상·컴포넌트 규칙은 [`design-tokens.md`](design-tokens.md)를 따른다. 확장 기능(OCR·사진 분석·크롤링·추천) 화면은 포함하지 않는다. 다만 진입점이 될 자리(제품 상세의 영양 입력, 외부 식사 입력)만 표시한다.

- 모바일 우선(360px 가로 스크롤 없음), PC는 통계·기간 비교를 강화한다(NFR-01, FR-07).
- 모든 화면은 로그인 사용자 데이터만 보여 준다. 화면이 ID를 조작해도 서버가 거부한다(NFR-04).
- 상태는 색상만으로 표시하지 않고 텍스트·아이콘을 함께 쓴다(NFR-01).
- 미전송·실패 상태를 ‘저장 완료’로 표시하지 않는다(NFR-03). 낙관적 UI 실패 시 서버 상태로 복구한다(NFR-02).

### 화면 어휘 대응표 (DEC-057)

이 문서와 코드·DB 는 도메인 용어(제품·재고·입고·소진)를 그대로 쓰고, **사용자에게 보이는 문구**만 집 어휘로 바꾼다. 새 화면을 만들 때 아래 표를 따른다.

| 도메인 용어 (문서·코드) | 화면 문구 |
| --- | --- |
| 제품 (Product) | 식품 |
| 재고 탭 | 식품 |
| 현재 재고 (`currentStock`) | 남은 양 |
| 재고 확인 필요 (`stockCheckNeeded`, 음수) | 남은 양 확인 필요 |
| 재고 비관리 (`isStockTracked=false`) | 수량 안 셈 |
| 재고 단위 (`stockUnit`) | 수량 단위 |
| 포장 1개당 재고 단위 수 (`unitsPerPackage`) | 포장 1개에 들어 있는 양 |
| 초기 재고 | 현재 보유 |
| 구매·입고 (S-34·S-35) | 장보기 / 구매 기록 |
| 입고 (`receive`), 입고 완료 (`received`) | 받았음 |
| 입고 수량 | 받은 양 |
| 소진 (재고 0) | 다 먹음 |
| 소진 예측·소진 임박 (단계 2) | 떨어질 날 / 떨어질 식품 |
| 재고 복구·재차감 | 남은 양 되돌림 / 다시 뺌 |
| 재고 현황·원장·보정 (S-40~S-42, 단계 2) | 남은 양 보기 / 남은 양 변동 기록 / 남은 양 맞추기 |
| 영양 출처 `label` | 포장 표시값 |
| 식사 유형 `home` | 식단 |

- 좌측 사이드바(토큰 `sidebar-*`)에 같은 5개 항목 + 제품·구매 하위 메뉴를 펼친다.
